# Spec v2.0.0 — 2026-10-02

Complete rebuild of the Aquarium widget. The v1 spec is replaced, not amended.

## Why

- v1 relied on swipes (cleaning, drag to place), which the Homey dashboard captures for scrolling.
- Art and animation did not line up: eels clipped through caves, decor overlapped the HUD.
- The 82 KB spec described more than was built, which made it hard to work from.

## Key decisions

- **Taps only.** Every interaction is a tap or a mode entered from the dock, followed by a tap.
- **Shared deterministic engine.** `public/engine.js` runs on the server (authoritative), in the page (optimistic) and in the sandbox. The client queues actions and replays them on each server response.
- **Four tanks:** pond, Amazon, reef and abyss, replacing fresh, tropical and saltwater. Coins, pearls and food are shared.
- **Long-term loop:** Fishdex with 3 colours per species (66 entries), breeding, mystery and golden eggs, aquarist levels 1–30, daily goals with streaks, and 21 achievements.
- **Fixed decor slots** (4 back, 4 front, S/M/L) instead of free x/y placement, so every layout looks composed and nothing covers the controls.
- **Procedural Canvas art** for all 22 species and 28 decor items. Caves clip their residents properly.
- **Writes only when needed.** Reads no longer write the save each time.
- **No migration from v1.** Old saves are replaced by a fresh tank plus a gift.

## Removed from v1

- Wipe-mask cleaning, laser-pointer play, tools (heater, skimmer, UV), weak state, plant growth and trimming.
- The `reset_state` and `debug_scenario` widget settings. Reset now lives in the in-game Help pages.
